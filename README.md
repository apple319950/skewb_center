# Skewb EG2 Center Trainer

這版的介面與操作模型以 edogaki 的 NS Center Trainer 為參考重新實作，題庫改成 EG2 center recognition。

## Cases

Full 16：

H, Z, U1, U2, TS1, TS2, ZC1, ZC2, O1, O2, X1, X2, W1, W2, S1, S2

Basic 9：

H, Z, U, TS, ZC, O, X, W, S

## GitHub Pages

把以下三個檔案放在 repository 根目錄：

- `index.html`
- `styles.css`
- `app.js`

然後到 GitHub **Settings → Pages → Deploy from a branch**，選 **main** 與 **/(root)**。
